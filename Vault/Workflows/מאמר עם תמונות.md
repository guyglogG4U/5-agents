# 🔁 Workflow: מאמר עם תמונות

## תיאור
כשהמשתמש מבקש מאמר **עם תמונות**, ראובן מתאם בין יעל ויובל לפי הסדר הבא.

## שלבים

```
1. ראובן → יעל
   ├── קולט מ: Content/ (או מהמשתמש)
   ├── כותב: Output/<slug>.md + .html
   └── מסמן: {{IMAGE_NEEDED: "..."}} בכל מקום שנדרשת תמונה

2. יעל → ראובן
   └── מחזירה: סיכום + רשימת placeholders (מיקום + תיאור)

3. ראובן → יובל (פעם אחת לכל placeholder)
   ├── שולח: תיאור התמונה מהplaceholder
   └── יובל שומר: yuval/outputs/<YYYY-MM-DD>-<slug>.png

4. ראובן משלב
   ├── מחליף כל {{IMAGE_NEEDED: ...}} בהפניה אמיתית
   ├── MD:   ![תיאור](../yuval/outputs/<file>.png)
   └── HTML: <img src="../yuval/outputs/<file>.png" alt="תיאור">

5. שמירה סופית ב-Output/ (אותם קבצים, עם תמונות)
```
