# 📂 yuval/ — תיקיית יובל

## מה היא עושה
תיקיית העבודה של [[../Agents/יובל — מעצב התמונות]].

## מבנה
```
yuval/
├── reference/        ← תמונות השראה לזיהוי הסגנון הוויזואלי
│   └── .gitkeep
└── outputs/          ← תמונות מוגמרות שיובל יצר
    └── <YYYY-MM-DD>-<slug>.png
    └── <YYYY-MM-DD>-<slug>.txt  (ה-prompt ששימש)
```

## reference/
יובל סורק תיקייה זו לפני כל יצירת תמונה. המשתמש מניח כאן תמונות שמגדירות את האסתטיקה הרצויה (סגנון, צבעים, קומפוזיציה).

## outputs/
כל תמונה נשמרת עם קובץ `.txt` מלווה שמכיל את ה-prompt המדויק. מאפשר לשחזר ולוודא עקביות.
