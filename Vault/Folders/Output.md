# 📤 Output/ — תיקיית פלט

## מה היא עושה
תיקיית **פלט** של המערכת. מכילה את התוצרים הסופיים שיעל יצרה — כל מאמר נשמר בשני פורמטים:
- `<slug>.md` — Markdown
- `<slug>.html` — HTML מעוצב

לאחר שיובל יוצר תמונות, ראובן מחליף את ה-placeholders `{{IMAGE_NEEDED: ...}}` בהפניות אמיתיות.

- `מאמר לדוגמא.md` + `.html` — מאמר מוגמר
